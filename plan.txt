The problem it solves: Enterprises drown in internal documents — contracts, SOPs, reports, policies. Employees waste hours searching. DocuMind lets organizations upload documents, ask natural language questions, and get cited answers — with full access control, audit logs, and async processing pipelines.

Full Tech Stack Mapping

```
Authentication & Authorization → JWT + OAuth2 (Google SSO), RBAC with Django Guardian
API Design                     → DRF with versioning, throttling, cursor pagination
AI Integration                 → LangChain, OpenAI/Gemini, pgvector (PostgreSQL extension)
Async Processing               → Celery + Redis (document ingestion pipeline)
Caching                        → Redis (query cache, session cache)
Database                       → PostgreSQL + pgvector, Row-Level Security per tenant
Search                         → Hybrid search (vector similarity + full-text via pg_tsvector)
Real-time UI                   → HTMX + Django Channels (WebSocket for progress updates)
Security                       → Rate limiting, input sanitization, tenant isolation
Fault Tolerance                → Celery retry logic, dead-letter queues, circuit breaker pattern
Performance                    → Query optimization, DB indexing, connection pooling (PgBouncer)
Observability                  → Structured logging (structlog), health check endpoints
Deployment (later)             → Docker + Docker Compose → AWS/GCP + CI/CD
```

Core Features (MVP Scope)
1. Tenant onboarding — register org, invite members, role assignment
2. Document ingestion pipeline — upload PDF/DOCX → chunk → embed → store in pgvector
3. AI Q&A interface — ask questions, get answers with source citations
4. Access control — users only query documents their role permits
5. Audit log — every query, upload, deletion logged with actor + timestamp
6. Usage dashboard — queries/month, docs count, token consumption (HTMX-powered)
7. API layer — full DRF API so it's usable by external clients too
What Makes It "5-Year Level"
* Multi-tenancy is something juniors never build. It shows system design maturity.
* pgvector inside PostgreSQL — no separate vector DB needed. Shows you think about operational simplicity.
* Celery pipeline with retry/dead-letter — shows you understand distributed systems failure modes.
* Hybrid search (semantic + keyword) — shows you understand real-world search tradeoffs.
How We'll Build It

* Phase 1 — Project setup, auth system, multi-tenancy foundation
